# 🌐 Nexus Solidário - Portal de Inclusão e Cidadania

Aplicação web desenvolvida no âmbito da disciplina de Desenvolvimento Front-End, com o objetivo de conectar voluntários a iniciativas de impacto social.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estrutura semântica e acessibilidade.
* **CSS3:** Variáveis nativas, Flexbox e Grid.
* **JavaScript (ES6+):** Módulos, SPA (Single Page Application) e LocalStorage.

## 🛠️ Como Executar
1. Abra a pasta do projeto no Visual Studio Code.
2. Utilize a extensão **Live Server** para abrir o ficheiro `index.html`.
